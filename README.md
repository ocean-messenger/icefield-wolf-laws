# 冰原狼群法则

> 一个关于狼群、寒冬和头狼的童话。

---

## 如果你正在经历这些

- 团队明明人不少，但干活的总是那几个，其他人都在摸鱼。
- 一开始大家干劲十足，后来不知道为什么就散了。
- 领头的人很能打，但总是一意孤行，听不进别人的话。
- 分钱、分功劳的时候，总有人觉得不公平，然后走人。
- 队伍越来越大，但战斗力反而越来越弱。

如果你遇到过其中任何一条，
不妨花十分钟，看看冰原上的狼群是怎么活过冬天的。

## 关于这个故事

它讲了一群狼，在严酷的寒冬里，怎么合作捕猎、怎么分配食物、怎么选出头狼，以及——怎么从内部把自己搞死。

它不教你怎么当狼王。
它只解释：什么样的狼群会散，什么样的狼群能活。
